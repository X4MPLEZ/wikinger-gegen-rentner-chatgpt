# Wikinger gegen Rentner

3D-Strategiespiel fürs Handy. Wikinger gegen Rentner, gegen den Computer oder online zu zweit.

Online-Spiel: Einer tippt auf „Spiel erstellen“, der andere öffnet dieselbe Seite und gibt den Code bei „Beitreten“ ein. Die Geräte verbinden sich direkt miteinander, eine Anmeldung ist nicht nötig.

Diese separate Entwicklungsfassung wird ausschließlich in
`X4MPLEZ/wikinger-gegen-rentner-chatgpt` gepflegt. Das Original bleibt unverändert.
